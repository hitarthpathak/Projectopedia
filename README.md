# ✨ Introducing, Projectopedia - A Project Management System (PMS) for managing a complete Project Lifecycle.

### 🚀 Key Features :
#### ✅ Architecture - Atomic Structure (reusable components)
#### ✅ State Management - Context API (global state management, without prop drilling)
#### ✅ Routing - React Router DOM and useNavigate() Hook (seamless navigation)
#### ✅ Performance Optimization - Lazy Loading, Conditional Rendering and Memoization
#### ✅ Storage - Local Storage (project and ticket data)
#### ✅ Custom Hooks, Portals, Lifting State Up, etc.

---

### 🛠️ Tech Stack : React JS, Tailwind CSS
